# Tiny Tracker

A tiny app to track anything in your daily life, fully offline.

## Features

- **Multiple tracker types**: Yes/No, count toward a target, 1 to 5 range, or running number log
- **Goal & neutral orientations**: goal trackers show streaks and a "Done" button; neutral trackers log values without judgement
- **Flexible frequency**: daily, weekly, or every N days
- **Routines**: group trackers into routines you complete together
- **Streaks**: automatic streak tracking for goal trackers
- **Graphs & insights**: trend lines, correlations between trackers, and an interactive force-directed graph of your data
- **Reminders**: optional per-tracker push notifications
- **Fully offline**: all data stored locally on device, no account required
